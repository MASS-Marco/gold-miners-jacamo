# Modelos propostos

BPMN de análise não executável, vista SVG e contrato de missões. A estrutura BPMN foi validada pelos esquemas oficiais da OMG; isso não demonstra execução em um motor ou integração com JaCaMo.

A recuperação deve conferir a carga antes de redistribuir a missão. Os campos e estados do contrato ainda não são produzidos pelo tutorial. O adendo acadêmico contém a justificativa e o desenho da comparação.

Antecedente: Cossentino, Lopes e Sabatucci (2020), [A Tool for the Automatic Generation of MOISE Organisations From BPMN](https://ceur-ws.org/Vol-2706/paper11.pdf). A ponte BPMN–Moise não é apresentada como inédita.
